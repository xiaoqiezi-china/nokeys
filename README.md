# NoKeys

Windows 上的全局轮盘 / 列表快捷启动器：按住一个热键，在鼠标处弹出轮盘，推向某个方向松手就执行对应功能。

## 功能

- **全局轮盘**：多个轮盘，每个最多 8 个功能项；打开时钉住指针，按方向选扇区
- **列表视图**：4:3 网格，每行个数可调，图标居中、名称在下
- **六种动作**：虚拟键 / 快捷键 / 程序 / 文本 / 命令 / 网页
  - 虚拟键：分配 F13–F24 中一个空闲键，可在别的软件或游戏里直接绑定
  - 快捷键：点"绑定"后按下组合即可，不用手写
  - 文本：支持 `{date}` `{time}` `{clipboard}` 占位符
- **自动填坑**：删掉的功能序号会被下一个新功能重新使用，虚拟键同理
- **实时毛玻璃**：轮盘背后的模糊是该区域屏幕的实时画面
- **常驻托盘**：左键打开设置，菜单可退出

## 安装

下载 `NoKeys-<版本>.msi` 双击运行标准的 Windows 安装向导：安装到 `Program Files\NoKeys`，
创建开始菜单与桌面快捷方式，注册到"应用和功能"，卸载也从那里走（或者再运行一次安装包选"删除"）。
安装需要管理员授权，安装完成后会自动启动。

不想安装就用便携版：解压 `NoKeys-<版本>-portable.zip`，直接运行 `nokeys.exe`。

配置与图标保存在 `%APPDATA%\NoKeys`，卸载时不会删除。

## 使用

1. 打开设置 → 通用，点"改绑"，按下你的热键（单键可用 F13–F24、鼠标侧键；字母数字需配 Ctrl/Alt/Win）
2. 轮盘页添加功能项，选择动作类型
3. 按住热键 → 推向某个方向 → 松手执行；原地松手则取消

轮盘打开期间只接管鼠标（指针被钉住，游戏读不到视角移动、点不到按键），键盘照常可用，`Esc` 取消。

## 已知限制

- 走原始输入（Raw Input）的游戏运行时仍可能接收到视角移动，系统层无法拦截
- 轮盘窗口对屏幕捕获不可见（避免抓到自己），需要截图时用 `NOKEYS_CAPTURE_VISIBLE=1` 启动
- 独占全屏下抓不到背景，轮盘会退化为无模糊

## 从源码构建

需要 Rust（MSVC 工具链）、Windows SDK（嵌入图标和版本信息）以及 WiX 3（生成 MSI）。

```
cargo build --release              # target\release\nokeys.exe
powershell -File _tools\pack.ps1   # dist\ 下生成 MSI 与便携版（需要 WiX 3，可用 WIX_BIN 指定）
```
